# Changelog

All notable changes to Mickey are listed here, newest first. The file is generated by `scripts/release.py`
from the commit messages (Conventional Commits) and the `v*` tags: do not edit it by hand. See
`docs/RELEASING.md`. Versions follow [Semantic Versioning](https://semver.org).

## [0.2.0] - 2026-11-06

### Added

- **ui**: Tooltips with shortcuts on toggles and buttons
- **a11y**: Honor the macOS Reduce Motion setting
- **a11y**: Name and describe controls for VoiceOver
- **annotations**: Redo with ⇧⌘Z and a toolbar button
- **settings**: Export and import settings as a JSON file
- **recorder**: Choose the quality and the frame rate
- **auto-mode**: Choose a preset per watched app
- **i18n**: French localization
- **annotations**: Copy the drawing to the clipboard as an image
- **ring**: Optional contrast outline
- **effects**: Live preview of the spotlight and ring in the settings
- **homebrew**: Cask template and a script that renders it

### Changed

- **i18n**: One tool and one procedure for every language

### Fixed

- **hotkeys**: Follow the keyboard layout and compare shortcuts by key
- **annotations**: Arrow keys and Mickey off no longer start drawing
- **studio**: Stop the capture retry loop and keep recordings intact
- **automode**: Give the user's settings back reliably
- **overlays**: Keep effects visible when Mickey is hidden
- **zoom**: Keep Mickey's own windows in the magnified picture
- **master**: Turning Mickey off stops everything
- **overlays**: Keep turned-off tools hidden when Mickey gets focus back
- **a11y**: Onboarding and settings cards also honor Reduce Motion
- **ui**: Wider label column in the settings rows
